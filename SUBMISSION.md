# Panta Signal Lens — submission copy

## Project name

Panta Signal Lens

## Project description

Panta Signal Lens turns prediction markets into an explainable intelligence feed for researchers, traders, and newsrooms. It ranks Panta markets by conviction, liquidity, and market phase, then opens each market into an evidence view with probability, volume, and recent YES versus NO trade flow. The product uses Panta's markets, categories, market-detail, and recent-trades API routes through a server-side proxy, while a clearly labeled public fixture keeps the interface reviewable without exposing credentials.
